Accessibility Statement

MyBrandFather is committed to making this website usable by as many people as possible, including people with disabilities. This site aims to follow recognized accessibility principles; we do not claim formal WCAG certification.

Keyboard Usability

Navigation, forms, and interactive controls on this site are operable by keyboard. A "Skip to content" link is available at the top of every page for keyboard and screen-reader users.

Readable Contrast

We aim for reasonable color contrast between text and backgrounds throughout the site. We are aware of a small number of decorative UI elements that could improve, and we're actively working through them.

Alternative Text

Meaningful images include descriptive alt text. Purely decorative images use empty alt attributes so screen readers skip them appropriately.

Reduced-Motion Support

This site includes scroll reveals, hover effects, and a background video. All motion respects your operating system's "reduce motion" preference — if enabled, animations are shortened or removed and effects are simplified automatically.

Ongoing Improvements

Accessibility is an ongoing practice, not a one-time checklist. We continue to test and refine keyboard navigation, focus states, and form accessibility across the site.

Third-Party Limitations

Some third-party embedded resources (such as fonts and icon libraries) are outside our direct control. We choose reputable providers and monitor for accessibility issues where practical.

Feedback

If you encounter a barrier using this site, please tell us. Email hello@mybrandfather.com with the page and a description of the issue, and we'll address it as soon as possible.
